# Bestiary

Enemies operate approximately like Seekers. Key differences:

- No Gambits, stats
- No explicit level

Basic enemy stat blocks have: HP, Evade, and Limit. Evade and Limit operate the same as with a Seeker.

For attacks, experienced enemies roll 3 or more d6. Roll the dice, and use the best 2. If no attack is displayed, take the bigger die for a Strong Hit.

Enemies can use the Finesse Gambit.
