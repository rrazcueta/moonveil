# Roguelike

Tested a roguelike mode for Moonveil.

## Why?

- Power fantasies are fun.
- Lots of popular BIG TTRPGs have them, but not many SMALL TTRPGs have them

Power fantasies are fun because we're spending time with these games and getting good at these games is fun - also it allows for more content. There's a fuzzy space where it trivializes older content. Some people like that and other people hate that.

I imagine that small TTRPGs don't have these because it's hard to do right. You only have so much content, and changing player abilities to target specific kinds of content makes it harder to play. You need a lot of content which means a lot of work beforehand or solutions to take existing content and move it to fit your game.

## How?

I made a real messy list of 36 skills players could get on level up. Leveling up means: more dice for rolling HP, an extra Ability Point, and now a skill. The skill is chosen from a list of 2 skills chosen from two d66 rolls.

This was intentionally messy and probably broken. I could get away with this because my group is a bunch of fun people that are OK seeing a mess.

## What happened?

I Guided 7 Seekers through 4 hours of dungeon crawling. There were some hijinks and four combat sessions.

Moonveil notes for myself

- Moonveil runs OK with 7 players. Unsure if other games would've fit the theme better. On the upper end of good.
- Transitioning from easy to set up Watabou One Page Dungeons to MV combat is not the cleanest - specifically converting those spaces to MV spaces is annoying. Doing JRPG style screen wipes into approximated battlefields is probably best.
- Combats take a while to set up. Rolling pocket for each enemy +HP is a lot of dice to roll.
- Transitioning into combat is interesting.
- Exploding damage was crazy

The team dove down stages of the dungeon after combat 2, and combat 3, so they leveled up twice.

Leveling up was pretty clean. Some players got great combos. Some players did not.

Some players had interesting skill combos, some players got single skills that changed how they played, and some players did not get anything they liked.

- Broken combos are very rare, but fun. They are enticing for further play.
- Some powerups were useful, many were not. That's unsatisfying

I can't be certain, but it seemed like players used Gambits less.

## Analysis

Skills should feed into the existing structure to reinforce the gameplay as opposed to offer an alternative. I want to push people to use Gambits.

The plan

- Let players draft by draft list that model archetypes or classes.
- Always let player draft something good
  - Maybe a "general" draft list
  - Or move the +d6 HP from level to a skill. This would double as a baseline power curve speed.
- Redo the skills to be more focused on existing gameplay hooks like Gambits

I don't really want to focus on power gaming, but I think the idea for long term play I think that will need to be considered. Limiting the number of skills you can have active would make it eventually feel like choosing a deck which is gamey and fun. That means there's a few entrypoints

- Early game: brand new characters, no/low skills
- Mid game: the skill deck is full of randomized skills
- End game: repeated play with a full skill deck to find new skills to optimize

This would make it easy to create tiers of dungeons. 6 skills seems about right. That means that's ~3 sessions to go from Early game to Mid game. To transition from Mid Game to late game is up to the individual player and the lists of skills and how combos are built from there. And then I'm imagining the End Game is something like the City Quest in Mythic Bastionland.
