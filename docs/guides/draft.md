# Drafting Skills

When drafting skills pick or choose two tables. Roll on each table. Pick between the two choices.

| d6  | Name    | First Table | Second Table |
| --- | ------- | ----------- | ------------ |
| 1   | Rogue   | Strength    | Dexterity    |
| 2   | Ranger  | Strength    | Insight      |
| 3   | Fighter | Strength    | Willpower    |
| 4   | Wizard  | Dexterity   | Insight      |
| 5   | Scout   | Dexterity   | Willpower    |
| 6   | Sage    | Insight     | Willpower    |
